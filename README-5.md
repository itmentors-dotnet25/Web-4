# 📚 Блок 5. Entity Framework Core с PostgreSQL

## 🎯 Общее описание
Интегрируйте Entity Framework Core и PostgreSQL в ваше REST API для библиотеки книг. Замените статическое хранилище на базу данных, реализуйте связи между сущностями и расширьте функционал API.

**Стек:** ASP.NET Core, Entity Framework Core, PostgreSQL, Docker, xUnit

---

## Важно!
Выполняйте это задание после выполнения блока 4. Создайте от ветки main свою, слейте эту ветку EF-Core-5 в вашу ветку и выполняйте задание.

## 📋 Задачи

### 🐳 Задача 1: Настройка базы данных

1. Запустите PostgreSQL контейнер в Docker с помощью предоставленной команды.
```
docker run -d \
  --name postgres-db \
  -e POSTGRES_DB=mydatabase \
  -e POSTGRES_USER=postgres \
  -e POSTGRES_PASSWORD=password \
  -p 5432:5432 \
  postgres:latest
```
2. Добавьте в проект необходимые NuGet пакеты для работы с EF Core и PostgreSQL.
3. Настройте строку подключения к базе данных в `appsettings.json`.
4. Зарегистрируйте контекст данных в DI-контейнере.

### 📊 Задача 2: Создание сущностей

1. Создайте сущность `Author` со свойствами:
    - `Id` (int, первичный ключ)
    - `FirstName` (string, обязательное)
    - `LastName` (string, обязательное)
    - `Bio` (string, необязательное)

2. Создайте сущность `Category` со свойствами:
    - `Id` (int, первичный ключ)
    - `Name` (string, обязательное, уникальное)
    - `Description` (string, необязательное)

3. Модифицируйте существующую сущность `Book`:
    - Добавьте свойство `CategoryId` (int, внешний ключ)
    - Добавьте свойство `AuthorId` (int, внешний ключ)
    - Добавьте навигационные свойства `Category` и `Author`
    - Удалите свойство `Author` из строки, так как теперь это будет связь с сущностью

4. Настройте связи в DbContext:
    - Одна книга принадлежит одному автору (Author → Books: один ко многим)
    - Одна книга принадлежит одной категории (Category → Books: один ко многим)

### 🗄️ Задача 3: Миграции

1. Создайте первую миграцию с созданием всех таблиц с именем `Initial`.
2. Примените миграцию к базе данных.
3. Убедитесь, что таблицы созданы в PostgreSQL.
4. Тестовые данные накатите вручную, скрипт представлен в items

### 🔍 Задача 4: Рефакторинг API

1. Обновите существующие CRUD endpoints для работы с базой данных (через Repository) вместо статического списка.
2. При создании книги теперь нужно указывать `AuthorId` и `CategoryId`.
3. При обновлении книги нужно обновлять связи с автором и категорией.

### 📈 Задача 5: Новые endpoints

1. **GET /api/books/with-details**
    - Возвращает список книг с полной информацией об авторе и категории
    - Используйте `Include()` для загрузки связанных данных

2. **GET /api/authors/{id}/books**
    - Возвращает все книги указанного автора
    - Включите информацию о категории для каждой книги

3. **GET /api/categories/statistics**
    - Возвращает статистику по категориям:
        - Название категории
        - Количество книг в категории
        - Средний год публикации книг в категории
    - Используйте группировку и агрегацию LINQ

### 🧪 Задача 6: Тестирование

1. Напишите unit тесты с помощью Moq для новых классов Repository.
2. Напишите интеграционные тесты для всех трех новых endpoints (только положительные сценарии, используйте TestContainers).
